# Hackathon finale

## KBC Loop – lenen in plaats van kopen (KBC-challenge)

KBC Loop is een marktplaats van circulaire partners in KBC Mobile. Klanten lenen producten
(verlichting, toestellen, elektronica, fietsen, babyspullen …) tegen een maandbedrag. De partner
blijft eigenaar, herstelt het product als het kapot gaat en neemt het terug voor hergebruik.
KBC herkent het juiste moment via Kate, brengt klant en partner samen en regelt financiering en
verzekering met bestaande KBC-diensten.

De demo staat in [`kbc-loop/`](kbc-loop/). Zie [`kbc-loop/README.md`](kbc-loop/README.md) voor
uitleg, opbouw en wat nog onaf is.

```bash
cd kbc-loop
npm install
npm run dev   # http://localhost:5173
npm test
```
